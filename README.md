A make.fun bounty entry. The program writes one word describing the boss to `/output/entry.txt`.

## The word

> ASAP

The boss is pure ASAP: everything is urgent, everything was due yesterday, and the word needs no caption to land.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 30 characters, not only whitespace, exactly one word.
